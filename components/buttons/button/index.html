Button

A versatile trigger button backed by the headless useButton hook. It composes focus, press, and semantic mixins to deliver complete keyboard, ARIA, loading, and icon behavior — with no styles baked in. Apply your own classes (or target the emitted data-variant / data-size attributes) to theme it.

Variants

Six semantic variants: default, secondary, outline, ghost, destructive, and link.

Preview

Sizes & states

Sizes sm / md / lg / icon, plus disabled and loading states (the loader is swappable via loadingIndicator).

Preview

With icons

Leading and trailing icon slots via leadingIcon and trailingIcon.

Preview

Props

NameTypeDefaultDescription
variant'default' | 'secondary' | 'outline' | 'ghost' | 'destructive' | 'link''default'Semantic visual variant. Emitted on data-variant for styling hooks.
size'sm' | 'md' | 'lg' | 'icon''md'Control density. Emitted on data-size.
loadingbooleanfalseDisables interaction and renders the loadingIndicator when provided.
disabledbooleanfalseDisables the button and sets aria-disabled.
fullWidthbooleanfalseSets data-full-width for stretch-to-container styling.
onPress(event: React.MouseEvent) => void—Primary press handler (guarded against loading/disabled).
leadingIcon / trailingIconReactNode—Icon slots rendered before/after the children.
loadingIndicatorReactNode—Custom node shown in place of content while loading.
render(props: ButtonRenderProps) => ReactElement—Escape-hatch custom renderer receiving state + handlers.
