Textarea

A multi-line text input backed by the headless useTextarea hook. It adds auto-resize, character counting, validation, and full ARIA semantics on top of the base input behavior — with no styles baked in.

Basic

A simple textarea with a label and helper text.

NameTypeDefaultDescription
value / defaultValuestring—Controlled or uncontrolled text value.
onChange(e: ChangeEvent<HTMLTextAreaElement>) => void—Change handler receiving the native textarea event.
labelReactNode—Label rendered above the textarea (click focuses).
helperTextReactNode—Supportive text shown beneath the textarea.
errorReactNode—Error message; sets aria-invalid and role="alert".
autoResizebooleanfalseGrow the textarea height to fit its content.
showCharCountbooleanfalseShow a live character count (pairs with maxLength).
charCountFormatter(current: number, max?: number) => string—Custom formatter for the character count text.
maxLength / disabled / requirednumber / boolean—Native field attributes reflected to ARIA.
